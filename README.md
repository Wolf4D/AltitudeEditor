# FPS Creator 2D Map Viewer (Qt5 C++)

[![Qt](https://img.shields.io/badge/Qt-5.15.2-green.svg)](https://www.qt.io/)
[![C++](https://img.shields.io/badge/C++-17-blue.svg)](https://en.cppreference.com/)
[![License](https://img.shields.io/badge/License-MIT-brightgreen.svg)](LICENSE)

Современный кроссплатформенный 2D-просмотрщик и анализатор карт для культового игрового движка **FPS Creator** (The Game Creators / DarkBasic Pro).

Разработано: **Иван Клёнов** (**Ivan Klenov**).

---

## 📌 Зачем создан этот проект?

Оригинальный редактор **FPS Creator** (V1, X9, X10, WASP, Classic V1.18+) проектировался в начале 2000-х годов под фиксированное разрешение и тяжеловесный 3D-режим на DarkBasic Pro. В современных условиях разработчикам и моддерам часто необходимо:
1. Быстро просматривать структуру многоэтажных уровней (`.fpm`) без запуска громоздкого редактора.
2. Видеть планировку комнат и текстуры стен в наглядном 2D-виде (в стиле классических редакторов уровней *Doom* / *Build Engine*).
3. Мгновенно искать любые игровые объекты (энтити, скрипты, источники света, маркеры, триггер-зоны, пути вейпоинтов).
4. Оценивать точный бюджет оперативной памяти уровня (Memory Budget) до компиляции и предотвращать вылеты по лимиту 32-битного движка (1.8–2.0 ГБ RAM).

**FPSC 2D Map Viewer** полностью решает эти задачи, обеспечивая высокую скорость работы, послойную визуализацию этажей и глубокую интеграцию с файлами движка.

## ✨ Основные возможности

- 🗺️ **Послойная 2D-визуализация карты (Doom-Style)**:
  - Отображение стен сегментов в виде текстурированных полос (linedefs) с контрастными контурами.
  - Поэтажный просмотр (Floors $0 \dots 20$) с мгновенным переключением.
  - Режим «Ghost Layer» (призрачный показ смежного нижнего/верхнего этажа для оценки лестниц и проемов).
- 🧩 **100% совместимость с бинарными форматами FPS Creator**:
  - Чтение зашифрованных и открытых `.fpm` (ZIP-контейнеры с паролем `mypassword`).
  - Побайтовое декодирование 3D-массива `map.fpmb` в формате DarkBasic Pro (Column-Major / Fortran order).
  - Распаковка битовых масок ячеек (Segment ID, Ground, Orientation, Rotation $0^\circ/90^\circ/180^\circ/270^\circ$).
  - Поддержка версий `map.ele` ($101 \dots 107, 199, 200, 217, 218$).
- 👾 **Полноценная отрисовка сущностей (Entities)**:
  - Автоматический хромакей (Color-Key Transparency) для 24-битных `.bmp` иконок и маркеров (устранение белых и черных рамок).
  - Отображение источников света с радиальными ореолами (Halo), триггер-зон, вейпоинтов и маршрутов патрулирования.
- 🔍 **Умный поиск и палитра (Entity Palette & Search)**:
  - Поиск по имени сущности, типу, используемому AI-скрипту, звукам или свойствам.
  - Фильтрация по категориям (Player Start, Персонажи, Оружие, Патроны, Пропсы, Двери, Свет, Зоны).
  - Фильтр «Только текущий этаж».
  - Двойной клик центрирует камеру на объекте.
- 📋 **Инспектор свойств (Entity Inspector)**:
  - Детальный просмотр всех параметров выделенного объекта: точные 3D координаты $(X, Y, Z)$, углы вращения, масштаб, AI-скрипты, параметры физики, параметры спавна и цвет/радиус освещения.
- 📊 **Встроенный анализатор памяти (Engine RAM Analyzer)**:
  - Расчет потребления памяти геометрии (`.x` меши), текстур (`.dds`, `.tga`, `.bmp`) и звуков (`.wav`, `.mp3`).
  - Индикатор риска переполнения 32-битного адресного пространства движка (Safe / Caution / Critical).

## ⌨️ Горячие клавиши

| Клавиша / Сочетание | Действие |
| :--- | :--- |
| **`+`** / **`=`** | Подняться на один этаж вверх (`Floor Up`) |
| **`-`** / **`_`** | Опуститься на один этаж вниз (`Floor Down`) |
| **`PageUp`** / **`PageDown`** | Навигация по этажам |
| **`Ctrl + Колесико`** / **`Shift + Колесико`** | Переключение этажей колесом мыши |
| **`[`** / **`]`** | Уменьшение / Увеличение масштаба (Zoom Out / In) |
| **`0`** | Сброс масштаба на 100% |
| **`Home`** | Поместить всю карту в экран (Fit Level in View) |
| **Зажатая ПКМ / СКМ** | Панорамирование холста (Pan Canvas) |
| **ЛКМ** | Выделение объекта на карте / снятие выделения |

## 🛠️ Сборка проекта

### Требования:
- **ОС**: Windows 7 / 8 / 10 / 11
- **Qt**: Qt 5.15+ (MinGW 32-bit или MSVC)
- **Компилятор**: MinGW 8.1.0 32-bit (или GCC / Clang / MSVC)
- **Система сборки**: CMake $\ge 3.16$, Ninja

### Инструкция по сборке (через PowerShell):

```powershell
# 1. Добавьте пути к Qt5 и MinGW в PATH:
$env:PATH = "C:\Qt5\5.15.2\mingw81_32\bin;C:\Qt5\Tools\mingw810_32\bin;C:\Qt5\Tools\Ninja;" + $env:PATH

# 2. Перейдите в каталог проекта и создайте папку сборки:
mkdir -p "C:\FPSC Maped\build"
cd "C:\FPSC Maped\build"

# 3. Сконфигурируйте проект с помощью CMake и генератора Ninja:
cmake -G "Ninja" -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH="C:\Qt5\5.15.2\mingw81_32" ..

# 4. Скомпилируйте проект:
ninja
```

### Запуск:
Запустите собранное приложение:
```powershell
& "C:\FPSC Maped\build\FPSCMapViewer.exe"
```
Либо используйте готовый скрипт [run_viewer.bat](file:///c:/FPSC%20Maped/run_viewer.bat).
